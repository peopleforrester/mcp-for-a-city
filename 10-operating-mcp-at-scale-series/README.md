# Operating MCP at Scale

A series of articles that carries the operational depth the fifteen-minute
keynote cut. The talk says the vetting chain ends with you; the series says
what you then have to build. One part per pillar, and a checklist that pulls
the actions from all five into one place.

**Start with the [enterprise checklist for 2026-07-28](operating-mcp-checklist.md)**
if you run a platform team. Every item names the specification requirement or
the part that argues it.
